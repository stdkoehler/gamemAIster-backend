You are building the combat-relevant stat block for a Shadowrun 6th Edition
NPC, given a narrative description of who they are.

Rules:
- `metatype` is one of Human, Elf, Dwarf, Ork, Troll (pick what best fits the
  description).
- `archetype` is a short label such as "Street Samurai", "Decker", "Mage",
  "Shaman", "Rigger", "Face", "Ganger", "Corp Security", etc.
- `attributes` covers Body, Agility, Reaction, Strength, Willpower, Logic,
  Intuition, Charisma, Edge (natural range 1-6, augmented up to 9), and
  Essence (0.0-6.0, reduced by cyberware). Only include Magic or Resonance if
  the archetype calls for it.
- `skills` should contain 3-6 combat/field-relevant skills (e.g. Automatics,
  Pistols, Rifles, Shotguns, Heavy Weapons, Blades, Clubs, Unarmed Combat,
  Archery, Throwing Weapons, Sneaking, Perception, Gymnastics, Pilot Ground
  Craft, Pilot Aircraft) rated 1-12, fitting the archetype and the NPC's
  competence level implied by the description and budget.
- `initiative_base` = Reaction + Intuition. `initiative_dice` is normally 1,
  raise it (2-4) for augmented/fast NPCs (e.g. with Wired Reflexes).
- `damage_physical_max` = 8 + ceil(Body / 2). `damage_stun_max` = 8 +
  ceil(Willpower / 2).

## JSON Structure

Respond with ONLY a JSON object matching this exact structure (no extra
commentary, no markdown outside the fenced block):

```json
{
  "metatype": str,
  "archetype": str,
  "attributes": {"Body": int, "Agility": int, "Reaction": int, "Strength": int, "Willpower": int, "Logic": int, "Intuition": int, "Charisma": int, "Edge": int, "Essence": float},
  "skills": dict[str, int],
  "initiative_base": int,
  "initiative_dice": int,
  "damage_physical_max": int,
  "damage_stun_max": int
}
```

Adhere strictly to this structure: `attributes` values are numbers (Essence
may have decimals, all others are whole numbers), `skills` values are
integers, all other fields are required.
