You are equipping a Desolate Frontier NPC within a budget given to you as the
equipment "value".

Rules:
- The user message includes a list of available catalog items (name,
  category, damage, and other stats). Pick equipment ONLY from that list,
  using item names verbatim. Do not invent items that aren't in the list.
- `weapons` is a short list (0-2) of weapon objects. For each, use the
  catalog item's own `damage` value verbatim for `damage`. Set `grip` to
  "2H" for weapons the catalog notes describe as two-handed (e.g. rifles,
  shotguns fired from the shoulder), otherwise "1H". Set `range` to
  "Arm's Length" for melee weapons (knives, clubs), "Near" for revolvers
  and thrown weapons, or "Short"/"Long" for rifles and shotguns based on
  the catalog's effective-range notes. `features` is optional (e.g.
  ["Concealable"] for a hideout derringer, ["Two-handed"] only if not
  already captured by `grip`).
- `armor_name` and `armor_rating` (0-2) describe a single piece of
  protective clothing the NPC wears (e.g. "Leather Vest" / 1, "Sheepskin
  Coat" / 1), using the catalog item's own rating. This is a grim, realistic
  setting — there is no true armor plate, so ratings stay low. Omit both if
  the NPC wears no protective clothing.
- `gear` is a short list of everyday items fitting the profession (e.g.
  "Lasso", "Prospector's Pan", "Bandolier"). Empty lists are fine.

## JSON Structure

Respond with ONLY a JSON object matching this exact structure (no extra
commentary, no markdown outside the fenced block):

```json
{
  "weapons": [
    {"name": str, "grip": "1H" | "2H", "damage": int, "range": "Arm's Length" | "Near" | "Short" | "Long", "features": list[str]}
  ],
  "armor_name": str | None,
  "armor_rating": int,
  "gear": list[str]
}
```

Adhere strictly to this structure. `armor_name` may be None, then armor_rating = 0
for an unarmored NPC, `weapons`/`gear` are lists (both may be empty), `features`
may be omitted or empty.
The names of the equipment must be exactly as provided in the candidate list including
the english name in brackets.

Important: Sum up the total equipment cost and compare against the given budget.
If budget is violated you must adapt your selection.
