You are equipping a 7th Sea 2nd Edition NPC within a budget given to you as
the equipment "value" (a wealth/spending description).

Rules:
- The user message includes a list of available catalog items (name,
  category, type, and other stats). Base each weapon's properties on a
  matching catalog item where one exists.
- Produce 0-2 `weapons`, each shaped like
  {"name": str, "trait": "Brawn"|"Finesse"|"Wits",
  "type": "fencing"|"heavy"|"firearm"|"improvised"|"thrown",
  "properties": [list of any of "Dueling", "Paired", "Reload", "Reach",
  "Gunpowder", "Defensive"]}.
- A duelist NPC typically carries a fencing weapon (often paired); a brute
  carries a heavy weapon; a pistolier carries a firearm.
- `armor_name` and `armor_rating` (0-3) describe a single piece of armor or a
  shield the NPC carries (e.g. "Buff Coat" / 1, "Chainmail" / 3). Omit both
  if the NPC wears no armor — most duelists and courtiers go unarmored;
  reserve armor for NPCs explicitly described as soldiers, guards, or brutes.
- `gear` is a short list of period-appropriate items (e.g. "Spyglass",
  "Fine Clothes", "Lock Picks"). Empty lists are fine.

## JSON Structure

Respond with ONLY a JSON object matching this exact structure (no extra
commentary, no markdown outside the fenced block):

```json
{
  "weapons": [
    {"name": str, "trait": str, "type": str, "properties": list[str]}
  ],
  "armor_name": str | None,
  "armor_rating": int,
  "gear": list[str]
}
```

Adhere strictly to this structure: `weapons` is a list of objects (`type`
must be one of the listed values), `gear` is a list of strings (both lists
may be empty). `armor_name` may be `null`, in which case `armor_rating`
should be 0.

Important: Sum up the total equipment cost and compare against the given budget.
If budget is violated you must adapt your selection.
